# Локалки

Приложение для строки меню macOS: показывает, какие локальные серверы у тебя подняты, и гасит их в один клик. Сделано для тех, у кого AI-агенты (Claude Code, Codex и т. п.) поднимают dev-серверы и забывают их выключать.

![macOS 14+](https://img.shields.io/badge/macOS-14%2B-black)

## Что показывает

- **Локалки** — процессы-рантаймы (node, python, bun, deno, ruby, php, uvicorn, gunicorn, java и всё из `node_modules`), которые слушают порт. Для каждого: проект, порты, тип (Vite, Next.js, Storybook, статика, API…), сколько висит, память. Действия: открыть в браузере, показать папку, остановить.
- **Погасить старше суток / Погасить все.** Остановка: SIGTERM, через 2 секунды SIGKILL; обёртка `npm exec` гасится вместе с сервером.
- **Что ещё грузит мак** — Docker (Colima, с кнопкой остановки), Claude, Codex, MCP-серверы, OBS: число процессов, память, CPU.

Системные службы и обычные программы в список не попадают: фильтр идёт по настоящему пути исполняемого файла (`proc_pidpath`), а не по имени процесса — node-инструменты подменяют имя (`http-server`, `next-server`).

## Установка

Нужны Command Line Tools (`xcode-select --install`).

```sh
git clone https://github.com/DanyaEast/localki.git
cd localki
./build.sh
```

`build.sh` собирает приложение через `swiftc`, подписывает ad-hoc, кладёт в `~/Applications/Локалки.app` и включает автозапуск через LaunchAgent.

Команду для подписей удобно положить в `PATH`:

```sh
ln -s "$PWD/bin/localki" ~/.local/bin/localki
```

## Подписи от агентов

Вместо папки в панели можно показывать человеческое имя и зачем сервер поднят:

```sh
localki name 5173 "Лендинг · прототип" "Проверка нового первого экрана"
localki list            # все подписи
localki unname 5173     # снять подпись
```

Подписи лежат в `~/.localki/names/<порт>.json`. Подпись, сделанная раньше запуска текущего процесса на этом порту, считается устаревшей. При остановке из панели подпись удаляется.

Чтобы агенты подписывали серверы сами, добавь в их правила (`AGENTS.md`, `CLAUDE.md`) строку вроде:

> Любой локальный сервер, который поднимаешь, сразу подпиши: `localki name <порт> "<Имя>" "<зачем>"`. Сервер больше не нужен — останови его.

## Папки проектов

По умолчанию имя проекта считается от домашней папки. Чтобы показывать короче, перечисли корни своих проектов в `~/.localki/roots`, по одному на строку:

```
~/Projects
~/work
```

## Удаление

```sh
launchctl bootout gui/$UID/com.danyaeast.localki
rm ~/Library/LaunchAgents/com.danyaeast.localki.plist
rm -rf ~/Applications/Локалки.app ~/.localki
```
